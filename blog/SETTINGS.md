# Blogger 手動設定（APIでは変更できない部分）

> いまの状態（2026-11-05）: ブログ名・説明は「ドット語り.」に変更済み。
> Blogger API ではテーマを変えられないため、`publish.py` が記事・固定ページの本文を `<div class="dt-wrap">` で包み、
> 末尾に `blog/inline.css`（明るいテーマ向けの本文用ドット調デザイン）を埋め込んでいます。
> 見出し・メニュー・トップページはテーマのままなので、トップと記事の見た目がそろいます。
> 下の 3.（`blog/theme.html` を貼る）は、ブログ全体を暗いドット調にしたい場合だけの任意作業です。
> 貼る場合は実際の画面に合わせた調整が要るので、貼ったあとにスクショで確認してください。

記事・固定ページ（このブログについて／プライバシーポリシー／訂正履歴）は
`engine/tools/publish.py` で自動更新できます。ブログ名・プロフィール・デザインだけは
Blogger の管理画面（https://www.blogger.com/）で手で変える必要があります。
スマホの場合は、ブラウザのメニューで「PC版サイト」にすると全部の項目が出ます。

## 1. ブログ名・説明（設定 → 基本）
- タイトル（「そもそも帖」をこれに置き換え）
```
ドット語り.
```
- 説明
```
ドットで描く、物語と記録。ボタンを押すと始まる、ドット絵の物語を置いています。
```

## 2. プロフィール（設定 → ユーザー設定 → ユーザープロフィール）
- 「プロフィールの種類」は **Blogger** を選ぶ（「Google」のままだと、Googleアカウント自体の名前・写真が表示される）
- 「Blogger のプロフィールを編集」から:
  - 表示名
```
ドット語り.
```
  - 自己紹介
```
■ ドット語り.（どっとがたり）
ドットで描く、物語と記録。

▶ ドット語り 文庫 … 語り部「記録の神」が名作文学をドット絵で語ります
▶ ドット語り 記録 … 語り部「灯の神」が本当にあった出来事を語ります（準備中）

ボタンを押すと始まる物語を、ひとつずつ置いていきます。
YouTube ▶ @dotgatari
TikTok ▶ @dotgatari
```
  - プロフィール画像: [`blog/profile.png`](profile.png)（768×768。開いて「Download raw file」で保存）

## 3. デザイン（テーマ → HTML を編集）
1. 念のため先にバックアップ: テーマ →「カスタマイズ」横の ▼ →「バックアップ」→ ダウンロード
2. 同じ ▼ →「HTML を編集」
3. [`blog/theme.html`](theme.html) を開き、右上の「Copy raw file」で全部コピー
4. HTML の中の `</head>` のすぐ上に貼り付けて、右上の保存アイコン
   - `</head>` が見つけにくいときは、いちばん上のほうにある `<head>` のすぐ下に貼ってもOK
5. 元に戻したいときは、貼った「▼▼ ドット語り ドット調デザイン ここから」〜「ここまで ▲▲」を消して保存

対応テーマ: Notable / Essential / Contempo / Soho / Emporio（2017年以降の標準テーマ）

## 4. カテゴリ（ラベル）
記事に付けるラベルで分けます（投稿時に自動で付けます）。
- `青空文庫シリーズ`
- `Wikipediaシリーズ`
レイアウト → サイドバーに「ラベル」ガジェットを追加すると、シリーズ別に一覧できます。

## 5. （任意）ブログのアドレス
設定 → 基本 →「ブログのアドレス」で `dotgatari.blogspot.com` を変えられます。
ただし変えると、今のアドレスで共有したリンク（記事URL・`works/*/published.json`）は開けなくなります。
変えた場合は `blog/pages/about.html` 内のお問い合わせリンクも直して `publish.py - pages` を実行してください。
