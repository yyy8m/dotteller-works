# Blogger 手動設定（APIでは変更できない部分）

## 1. ブログ名・説明（設定 → 基本）
- タイトル: `DOT TELLER`
- 説明: `■ ドットで描く、物語と記録。ボタンを押すと始まる、ドット絵の物語を置いています。▶ 青空文庫シリーズ ▶ Wikipediaシリーズ`

## 2. プロフィール（右上のアイコン → 自分のプロフィール → 編集）
- 表示名: `DOT TELLER`
- 自己紹介:
```
■ DOT TELLER（ドットテラー）
ドットで描く、物語と記録。

▶ 青空文庫シリーズ … 語り部「記録の神」が名作文学をドット絵で語ります
▶ Wikipediaシリーズ … 語り部「灯の神」が本当にあった出来事を語ります

小さい子から大人まで、ドット絵が好きな気持ちを忘れずに。
ボタンを押すと始まる物語を、ひとつずつ置いていきます。
YouTube ▶ @dotteller
```
- プロフィール画像: アイコン画像（DOT TELLER ロゴ）

## 3. デザイン（テーマ → カスタマイズ → 詳細設定 → CSS を追加）
- `blog/theme.css` の中身をそのまま貼り付け
- おすすめテーマ: Contempo または Essential（背景が暗くても崩れにくい）

## 4. カテゴリ（ラベル）
記事に付けるラベルで分けます（投稿時に自動で付けます）。
- `青空文庫シリーズ`
- `Wikipediaシリーズ`
レイアウト → サイドバーに「ラベル」ガジェットを追加すると、シリーズ別に一覧できます。
