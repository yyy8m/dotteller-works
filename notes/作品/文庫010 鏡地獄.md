# 文庫010 鏡地獄

#作品
- 鏡地獄（010-kagami-jigoku、江戸川乱歩、1965年没・青空文庫に著作権存続の印なし）。11/21 12:00 予約：本編 36ELFX5ESfw（9分05秒）／ショート WVjDO5qXv1Q（69秒）／TikTok 版 69秒（ループ）。
- 語り 2,513字。Ｋの話として、少年時代の「寿」の鏡 → 凹面鏡 → 実験室（望遠鏡・のみ・実物幻灯）→ 転換点「やがて彼は、もっと恐ろしいものを」鏡の部屋 → 衰え・ガラス工場 → ある朝の転がる玉 → 発狂 → 鏡の球の秘密。のぞき・恋人の娘は控えめに。
- 実験室の場面が静かすぎて QC の「動きが少ない」が多数出たので、story.js で全場面にゆっくりしたカメラの揺れとほこりの粒を足した（夢十夜も同じ）。
- 別エージェント点検6件（凹面鏡の顔の使い回し、文字のはみ出し、笑い声の位置、裸の人影を暗く、這い出す姿勢、赤い唇）を直した。
