# 都市伝説003 人面犬

#作品
- 人面犬（t003-jinmenken）。11/24 18:00 予約。
- 台本は書き下ろし（約2,720字）。広まった時期・雑誌やテレビ・江戸時代の書きもの・90年代に静まった等はすべて伝聞にした。裏通りの話（「うるせえな」）と、霧の夜の家族の車の話（「止めろ」→横倒しのトラック→「去年死んだ、おじいちゃんの顔だった」）を語る。中盤の転換点は「ところが。人面犬の噂には、ほかの怪物とは違う、妙なところがありました」（襲わない怪物）。
- 話者：jinmen（人面犬・m001 低め rough）、ken（男の子・mei）、chichi（父親・m001）。説明欄・ブログに mei のクレジットあり。
- 人面犬の絵：薄茶色の雑種の体（64x48）に中年の男の顔（垂れた犬の耳・無精ひげ・目の下のくま）。おじいちゃんの顔は old（白髪・日焼け・しわ）。
- 別エージェント点検12件（車の中の男の子が道路に立って見える→窓の内側に顔、後ろの席の子が見えない、大きな文字と犬の重なり、札からはみ出す文字、ゴミ袋に頭を入れた絵が首のない犬に見える、トラックが分かりにくい→札、暗すぎる影絵、高校生が大人に見える 等）を直した。
- BGM 名 'sorrow' はエンジンにない（書き出しが止まる）→ memory / requiem に。
