#技術

## 作る流れ
`docs/PRODUCTION.md` の順に進める：台本 → 読みチェック → 場面 → 音声 → ビルド → 一覧画像で点検 → 書き出し → 投稿。

## 主な部品（engine/src/kiroku.js。文庫でも lines.json の work に `"kit": "kiroku"` を書けば使える）
- `robeFig(st, o)`：和装・中国風の人物。立つ・座る・おじぎ・ひざまずく、腕・表情を変えられる。
- `suitFig(st, o)`：洋装の人物。帽子は hunt / bowler / straw。簔は `mino`。上着なし（noCoat）、クリーム顔（cream）もある。
- `closeUp(c, t, face, o)` と各作品の `withCuts`：セリフの間だけ顔を大きく映す。
- `glow(c, x, y, rx, ry, col, a)`：柔らかい光。`E(..., DA(col, a))` で光を描くと点々の輪になるので使わない。
- `PORTRAITS` と `withMouth`：会話ウィンドウの顔。しゃべると口が動く。
- `wideDY` / `tallFit`：横長での絵の上ずらし（既定24）と、ショートで横幅いっぱいに映す設定。場面ごとに変えられる。

## つまずいた所と対処
- **同じファイルに2つの書き出しを同時に走らせると壊れる**：途中の wav を消し合う。書き出しは作品ごとに1本ずつ、終わってから次を始める。
- **場面の変数名がエンジンとぶつかる**：例として `TL`（タイムライン）。杜子春は場面名を Z* に変えた。
- `TX` の色に `DA()` を渡すと書き出しが止まる。半透明にしたいときは `globalAlpha` を使う。
- **予約の解除**：`publishAt: None` を送ってから読み戻し、消えたか確かめる（1回で消えないことがある）。
- **動画の削除**：ID を直接書き、タイトルを確かめてから消す（ファイルから ID を読むと止められた）。
- **Wikipedia の取得**：API は回数制限があるので、index.php の raw に User-Agent を付けて取る。
- **青空文庫の取得**：www.aozora.gr.jp は環境で許可済み。Shift_JIS の XHTML なので、main_text からルビを除いて取り出す。
- **書き出した動画の確認**：`ffmpeg -v error -i x.mp4 -f null -` でエラー0行を確かめる。そのうえで、動画からコマを抜いて新しい絵になっているか見る。
- 場面の中で `const glow = ...` のように部品と同じ名前の変数を作ると、`glow()` が使えなくなる。部品と同じ名前は避ける。
- Blogger の予約中・下書きの記事は、`posts/{id}?view=ADMIN` でないと 404 になる。
- ブログのアドレスを変えたら `publish.py - blogsync` を実行する（古いアドレスからは転送されない）。
- サムネは横長（`thumb.png`、本編用）と縦長（`thumb_tall.png`、ショート用）の2枚。縦長は作品の `thumb.js`（`thumbBigFace` の設定）から自動で作られる。
- ショートの「関連動画」（本編へのリンク）は API では設定できない。オーナーが YouTube Studio で設定する。選べるのは公開済みの動画だけなので、予約の作品は公開後（19:00過ぎ）に設定する。定期作業の報告で、前日に公開した作品の設定をオーナーに頼む。
