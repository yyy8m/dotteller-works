#技術

## 作る流れ
`docs/PRODUCTION.md` の順に進める：台本 → 読みチェック → 場面 → 音声 → ビルド → 一覧画像で点検 → 書き出し → 投稿。

## 主な部品（engine/src/kiroku.js。文庫でも lines.json の work に `"kit": "kiroku"` を書けば使える）
- `robeFig(st, o)`：和装・中国風の人物。立つ・座る・おじぎ・ひざまずく、腕・表情を変えられる。
- `suitFig(st, o)`：洋装の人物。帽子は hunt / bowler / straw。簔は `mino`。上着なし（noCoat）、クリーム顔（cream）もある。
- `closeUp(c, t, face, o)` と各作品の `withCuts`：セリフの間だけ顔を大きく映す。
- `glow(c, x, y, rx, ry, col, a)`：柔らかい光。`E(..., DA(col, a))` で光を描くと点々の輪になるので使わない。
- `PORTRAITS` と `withMouth`：会話ウィンドウの顔。しゃべると口が動く。
- `wideDY` / `tallFit`：横長での絵の上ずらし（既定24）と、ショートで横幅いっぱいに映す設定。場面ごとに変えられる。

## つまずいた所と対処
- **「終わるまで待つ」ループに `pgrep -f 名前` を使わない**：待っている自分のコマンド行にもその名前が入るので、永久に待ち続ける（2026-11-09 と 11-12 の2回、書き出しが始まらなかった）。待つなら `wait` か、書き出しを1つのスクリプトに順番に並べる。
- **同じファイルに2つの書き出しを同時に走らせると壊れる**：途中の wav を消し合う。書き出しは作品ごとに1本ずつ、終わってから次を始める。
- **場面の変数名がエンジンとぶつかる**：例として `TL`（タイムライン）。杜子春は場面名を Z* に変えた。
- `TX` の色に `DA()` を渡すと書き出しが止まる。半透明にしたいときは `globalAlpha` を使う。
- **予約の解除**：`publishAt: None` を送ってから読み戻し、消えたか確かめる（1回で消えないことがある）。
- **動画の削除**：ID を直接書き、タイトルを確かめてから消す（ファイルから ID を読むと止められた）。
- **Wikipedia の取得**：API は回数制限があるので、index.php の raw に User-Agent を付けて取る。
- **青空文庫の取得**：www.aozora.gr.jp は環境で許可済み。Shift_JIS の XHTML なので、main_text からルビを除いて取り出す。
- **書き出した動画の確認**：`ffmpeg -v error -i x.mp4 -f null -` でエラー0行を確かめる。そのうえで、動画からコマを抜いて新しい絵になっているか見る。
- 場面の中で `const glow = ...` のように部品と同じ名前の変数を作ると、`glow()` が使えなくなる。部品と同じ名前は避ける。
- Blogger の予約中・下書きの記事は、`posts/{id}?view=ADMIN` でないと 404 になる。
- ブログのアドレスを変えたら `publish.py - blogsync` を実行する（古いアドレスからは転送されない）。
- サムネは横長（`thumb.png`、本編用）と縦長（`thumb_tall.png`、ショート用）の2枚。縦長は作品の `thumb.js`（`thumbBigFace` の設定）から自動で作られる。
- ショートの「関連動画」（本編へのリンク）は API では設定できない。オーナーが YouTube Studio で設定する。選べるのは公開済みの動画だけ。そのため本編18:00、ショート20:00と時間をずらして公開し、その2時間の間にオーナーが予約中のショートへ関連動画を設定する（`SHORT_DELAY_H`、作品ごとに変えるなら publish.json の `short_publish_at`）。
- 関連動画を自動で設定する方法は調べた範囲でない（Data API v3 に項目なし。Studio を画面操作で自動化するには Google のログイン情報をクラウドに置く必要があり、安全面と規約の面でやらない）。ショートの説明欄・コメントのリンクは押せないので代わりにならない。

## 横長の画角と字幕ウィンドウ（2026-11-08）
- 横長は元絵の y = dy〜dy+180 を映す（既定 dy=24）。字幕ウィンドウの上端は元絵のおよそ y = dy+135。それより下は隠れる。
- 場面ごとに `X.wideDY = 数値` か `X.wideDY = (t, S) => 数値`（場面の途中で変えられる）で調整する。地面の人物（y150〜165）は dy≈40、床下（y102〜158）は dy≈56。
- dy を上げると上が切れる。月などの空の物は `skyY(y)` で描くと、映る範囲の上端に合わせて下がる（`moon()` は対応済み）。見出しの文字は dy より下に置く。
- 点検：全セリフの真ん中の時刻で横長フレームを書き出して並べる（scratchpad の allfr.js と sheet.py）。隠れ・上切れを公開前に見る。
## ショートの縦サムネ
- テレビなどでは縦サムネが 2:3 くらいに切られる（上下が約9%ずつ消える）。中身は上下 TT_SAFE=34px（320px中）の内側に置く（`drawThumbTall`）。
## ショートの縦画面で文字が切れる件（2026-11-12）
- 縦画面は場面の 180x180 をカメラの注目点のまわりで切り取るので、左右の端にある文字（吹き出し・看板・札）が切れていた（西口彰事件の「弁護士会は？」など）。
- エンジンで自動的に防ぐようにした：場面に描いた文字の画像（`textSpr` と、それを薄めた `ditherFade`）の位置を記録し（`window.__txtScreen`）、縦画面の切り取りが文字を切るときは、文字と注目点がおさまるように切り取りをずらす。入りきらないときは全幅（`tallFit` と同じ）で見せる。
- 自前の小さなキャンバスに文字を描いてから貼る場合は記録されないので、文字は場面のキャンバスに `TX` / `bigCap` で直接描く。
- 確認：scratchpad の cutscan.js で、切り取りを調整したコマの時刻を一覧できる。
