ドット語り.

■ プライバシーポリシー（最終更新：2026年11月4日）

1. 対象

本ポリシーは、ドット語り（以下「当チャンネル」）が運営する作品サイト（https://yyy8m.github.io/dotteller-works/）、ブログ、YouTube チャンネル（@dotgatari）、および作品の投稿に使用するアプリケーション「ドット語り」に適用されます。

2. Google API の利用について

アプリケーション「ドット語り」は、運営者自身の Google アカウントで、運営者自身のブログ（Blogger）への記事投稿と、運営者自身の YouTube チャンネルへの動画アップロードを行うためだけに、Google API（Blogger API、YouTube Data API）を使用します。

第三者のアカウント情報やデータを取得・保存・共有することはありません。取得した認証情報は投稿作業以外の目的には使用せず、第三者に提供しません。

当アプリによる Google API から受け取った情報の使用は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に準拠します。

3. 作品サイトでの情報の取り扱い

作品サイトでは、個人情報の入力を求めません。アクセス解析や広告のための Cookie も使用していません。ドット書体の表示のため、Google Fonts からフォントを読み込みます。

4. お問い合わせ

本ポリシーに関するお問い合わせは、YouTube チャンネル @dotgatari までお寄せください。
