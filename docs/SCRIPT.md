# 脚本と演出の決まり（プロのドラマ脚本の水準）

返事・台本は日本語。事実（記録）・原作（文庫）から外れない範囲で、ドラマとして組み立てる。

## 1. 構成（本編）
1. **コールドオープン（0〜20秒）**：タイトルより前に、いちばん強い一瞬を見せる。説明はしない。問いだけを残す。
   - 例：「陽気なピエロ。誰もが、そう信じていました。その家の床下に、何が眠っていたのか――」→ ここで初めてタイトル。
2. **第1幕（日常と人物）**：主人公（犯人・被害者・語りの中心）が何を欲しがり、何を恐れているかを見せる。後で効いてくる「小道具・言葉」をここで置く（伏線）。
3. **転換点**：時計を止める一行（「時計の針を、少し戻します」「その夜、すべてが変わります」）。
4. **第2幕（積み上げ）**：出来事を並べるのでなく、緊張を一段ずつ上げる。1場面に1つの新しい情報。
5. **山場**：最も重い事実は、言葉を減らして、間（0.8〜1.5秒）と音で見せる。
6. **結末と余韻**：最初に置いた言葉・小道具を回収する（呼応）。犠牲者・人物への視線で終わる。説教しない。

## 2. 台詞と語り
- 1文は短く。句点で止める。「〜でした。」を3回続けない。体言止め・倒置を混ぜてリズムを作る。
- 語り部は全部を説明しない。見ればわかることは言わない（絵に任せる）。
- 人物の声は、記録・原作にある言葉を優先。ない場合は短い反応（「なんだ、これは……」）だけ。
- 数字は、効かせたいものだけを言い切る（「33人。」）。
- 文末の決めは、各章の最後の一行に置く。
- **「けれど」は使わない**（オーナー決定 2026-11-15：AI臭い）。「しかし」「だが」「ところが」も原則使わず、1作品で合わせて2回まで。対比は接続詞なしで文を並べて伝える（「お金は、返せない。二人は、殺害を決めた。」）。台本を書いたら `grep けれど` で0件を確かめる。
- **文末を散らす**：「〜でした。」「〜しました。」を2回続けない。体言止め（「硝酸ストリキニーネ。」）、言い切り（「〜なのです。」「〜の末路。」）、現在形（「〜が見つかります。」）を混ぜる。語り部（灯の神・記録の神）の丁寧な口調はそのまま。

## 3. 演出の指示（場面づくりに反映する）
- **画**：寄り（顔・手・小道具）と引き（町・家・夜空）を交互に。重い一行の前は引き、言い切りで寄る。
- **間**：山場の前後は items に 0.8〜1.5 の間を入れる。音楽を止める・効果音だけにする場面を1作品に1〜2か所。
- **音**：心音・風・時計・扉など「状況の音」を先に鳴らし、言葉は後から。
- **動き**：場面ごとに主役の動きを1つ決める（雪の夜は吹雪、駅は電車、法廷は木槌など）。話している人物は口を動かす（`docs/PRODUCTION.md` 4.55）。
- **色**：章ごとに色を変える（昼の暖色 → 夜の青 → 山場の赤 → 結びの灯）。

## 3.5 残酷な描写の線引き（オーナー決定 2026-11-15）
- **本編の中盤以降は、生々しさを今より強めてよい**：血だまり・血の跡、現場の跡（荒れた部屋・凶器・ブルーシート）、犯人の手元、壁の影絵や逆光のシルエットでの犯行、犯人の不気味なドアップ（`horrorCloseup`）、効果音で見せる暗転。
- **サムネ・本編の最初の30秒・ショート・TikTok は控えめ**：血や遺体を大きく出さない（YouTube の「広告に適したコンテンツ」で、サムネと冒頭が強いと広告制限・年齢制限になりやすい。8分以上にした目的の途中広告が減る）。
- **子どもが被害者の回は、被害者・犯行を描かない**（ろうそく・ポスター・消えていく姿で表す）。
- 遺体の損壊・解体そのものは描かない（現場・道具・煙・音で示す）。

## 4. 長さ
- **本編：8分以上は固定**（オーナー決定 2026-11-15。8分以上だと動画の途中に広告を入れられる）。11/26 公開分の制作から。11/25 までに予約済みの作品は作り直さない。
  - **語りの総字数は2,500〜3,000字以上**（オーナー決定）。話す速さを 1.18 に上げた（1分あたり約270字）ので、約9〜11分になる。若い視聴者は効率重視なので、間延びさせず密度で長くする。
  - 水増しはしない。字数は、記録なら記事の中の別のエピソード・人物・捜査の行き詰まり・その後、文庫なら原作の場面と台詞を増やして足す。記録シリーズは**記事にない話は入れない**ので、題材は本文が十分に長い記事（目安：脚注などを除いた本文20KB以上）から選ぶ。足りない題材は順番を後ろに回す（例：シップマン、ハールマン）。
  - **中盤の転換点**：4〜5分ごろに「ここで事態が変わる」場面（実は〇〇だった、捜査の急展開、人物の裏の顔）を必ず置き、後半の緊張を作り直す。
  - **真実を明かす前の「間」**：いちばん重い事実の直前に、items で1〜1.5秒の間（音楽だけ・効果音だけ）を置く。1作品に2〜3か所。
- **ショート：60秒以上**（5章）。0〜1秒目で問いを出す。1場面の山場だけを見せ、答えは言わない。冒頭と最後がつながる（ループ）。
  - 実績（11/8 時点）：45秒前後のショートで、エド・ゲインは1,100回再生、文庫は140〜200回。本編へはほとんど流れていない → ショートは短く鋭く、本編への関連動画リンクを必ず付ける。

## 5. ショートの決まり（CEO決定 2026-11-10。Gemini の台本プロンプトのルールが前提）
- **尺は1分以上（60秒超）に統一**。目安60〜75秒。
- **冒頭フック（最初の2秒）**：年号・地名・事件名・説明から始めない。いちばんショッキングな「結果」「異常性」「悲惨な末路」を短い言葉で最初に叩きつける。絵も0秒目から山場を見せる。
  - 良い例：「窓を突き破ってきたのは、1頭のヒグマでした。」「テントは、内側から、切り裂かれていた。」　悪い例：「1888年、ロンドン。」
- **テンポ**：1文を極力短く。体言止めを多用。説明や無駄な間を省き、次々と情報が展開する。
- **結末は出さない**：事件の結末・オチ・どんでん返しは本編に残し、いちばん気になる山場の手前で切る。
- **ループ構造**：最後のセリフ（S2）が、冒頭のセリフ（S1）に違和感なくつながる文にする（2周目に気づかず入る）。例：S2「彼女は、まだ知らない。今日も腰かける、」→ S1「毎日座っている、その椅子の中に、男が、ひとり。」
  - YouTube ショートには「続きは本編で」の札は出さない（ループが切れる）。本編への誘導は関連動画（公開直後に設定）・説明欄・画面下の「本編はチャンネルで」で行う。
- 作り方：`PLAN_TIKTOK` と同じ場面構成で、最後の `T1` を `S2` に替えたものがショート（`story.js` の `const PLAN = …` の行）。
- 事実は本編と同じく記録・原作の範囲で。ループのために事実を曲げない。

## 6. TikTok 版（2026-11-10 から。2026-11-15 にループへ変更）
- 60〜75秒。冒頭はショートと同じ S1。本編の場面を3〜4つ積み上げ、山場の手前で切る。
- **最後はショートと同じループ**（S2 → S1）。「続きは、本編で。」の T1 と「▶ 続きは本編で」の札は使わない（オーナー決定 2026-11-15）。TikTok はおすすめに載るかを見終わり率・くり返し再生で決めるため、ループの方が伸びやすい。本編への誘導は投稿文・プロフィール・画面下の「本編はチャンネルで」で行う。
  - 作り方：`story.js` は `const PLAN = SHORT ? PLAN_TIKTOK.map(T1 → S2) : PLAN_FULL;`（TikTok 版とショートが同じ構成）。`main.js` の札は `TIKTOK_CARD` を立てない限り出ない。
- **中間のつかみ**：ちょうど半分（約30〜35秒）の所に、もう一度興味を引き直す一文を置く（例：「本当の恐怖は、ここからでした。」）。事実の範囲で、本編の台詞から選ぶか、`T2` として足す。
- **2〜3秒ごとに絵を変える**：場面の切り替え・寄り・揺れ・スタンプ・年カードのどれかで、2〜3秒ごとに画面に新しい変化を入れる。
