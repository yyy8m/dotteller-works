# 脚本と演出の決まり（プロのドラマ脚本の水準）

返事・台本は日本語。事実（記録）・原作（文庫）から外れない範囲で、ドラマとして組み立てる。

## 1. 構成（本編）
1. **コールドオープン（0〜20秒）**：タイトルより前に、いちばん強い一瞬を見せる。説明はしない。問いだけを残す。
   - 例：「陽気なピエロ。誰もが、そう信じていました。けれど、その家の床下には――」→ ここで初めてタイトル。
2. **第1幕（日常と人物）**：主人公（犯人・被害者・語りの中心）が何を欲しがり、何を恐れているかを見せる。後で効いてくる「小道具・言葉」をここで置く（伏線）。
3. **転換点**：時計を止める一行（「けれど、時計の針を少し戻します」「その夜、すべてが変わります」）。
4. **第2幕（積み上げ）**：出来事を並べるのでなく、緊張を一段ずつ上げる。1場面に1つの新しい情報。
5. **山場**：最も重い事実は、言葉を減らして、間（0.8〜1.5秒）と音で見せる。
6. **結末と余韻**：最初に置いた言葉・小道具を回収する（呼応）。犠牲者・人物への視線で終わる。説教しない。

## 2. 台詞と語り
- 1文は短く。句点で止める。「〜でした。」を3回続けない。体言止め・倒置を混ぜてリズムを作る。
- 語り部は全部を説明しない。見ればわかることは言わない（絵に任せる）。
- 人物の声は、記録・原作にある言葉を優先。ない場合は短い反応（「なんだ、これは……」）だけ。
- 数字は、効かせたいものだけを言い切る（「33人。」）。
- 文末の決めは、各章の最後の一行に置く。

## 3. 演出の指示（場面づくりに反映する）
- **画**：寄り（顔・手・小道具）と引き（町・家・夜空）を交互に。重い一行の前は引き、言い切りで寄る。
- **間**：山場の前後は items に 0.8〜1.5 の間を入れる。音楽を止める・効果音だけにする場面を1作品に1〜2か所。
- **音**：心音・風・時計・扉など「状況の音」を先に鳴らし、言葉は後から。
- **色**：章ごとに色を変える（昼の暖色 → 夜の青 → 山場の赤 → 結びの灯）。

## 4. 長さ
- **本編：6〜8分**。だらだら説明する場面は削り、山場と人物の場面に時間を使う。最初の30秒で離脱させない（コールドオープン）。
  - 8分を超えると広告を途中に入れられる（収益化後）が、内容が水増しになるなら8分未満でよい。
- **ショート：60秒以上**（5章）。旧：25〜35秒。0〜1秒目で問いを出す。1場面の山場だけを見せ、答えは言わない。最後の一言で本編へ（「答えは、本編で。」）。冒頭と最後がつながる（ループ）ように作るとよい。
  - 実績（11/8 時点）：45秒前後のショートで、エド・ゲインは1,100回再生、文庫は140〜200回。本編へはほとんど流れていない → ショートは短く鋭く、本編への関連動画リンクを必ず付ける。

## 5. ショートの決まり（CEO決定 2026-11-10。Gemini の台本プロンプトのルールが前提）
- **尺は1分以上（60秒超）に統一**。目安60〜75秒。
- **冒頭フック（最初の2秒）**：年号・地名・事件名・説明から始めない。いちばんショッキングな「結果」「異常性」「悲惨な末路」を短い言葉で最初に叩きつける。絵も0秒目から山場を見せる。
  - 良い例：「窓を突き破ってきたのは、1頭のヒグマでした。」「テントは、内側から、切り裂かれていた。」　悪い例：「1888年、ロンドン。」
- **テンポ**：1文を極力短く。体言止めを多用。説明や無駄な間を省き、次々と情報が展開する。
- **結末は出さない**：事件の結末・オチ・どんでん返しは本編に残し、いちばん気になる山場の手前で切る。
- **ループ構造**：最後のセリフ（S2）が、冒頭のセリフ（S1）に違和感なくつながる文にする（2周目に気づかず入る）。例：S2「彼女は、まだ知らない。今日も腰かける、」→ S1「毎日座っている、その椅子の中に、男が、ひとり。」
  - YouTube ショートには「続きは本編で」の札は出さない（ループが切れる）。本編への誘導は関連動画（公開直後に設定）・説明欄・画面下の「本編はチャンネルで」で行う。
- 作り方：`PLAN_TIKTOK` と同じ場面構成で、最後の `T1` を `S2` に替えたものがショート（`story.js` の `const PLAN = …` の行）。
- 事実は本編と同じく記録・原作の範囲で。ループのために事実を曲げない。

## 6. TikTok 版（2026-11-10 から）
- 60〜75秒の予告編（TikTok の報酬対象が1分以上のため）。冒頭はショートと同じ S1。本編の場面を3〜4つ積み上げ、山場の手前で切る。
- 最後は `T1`（例：「白バイの男は、どこへ消えたのか。続きは、本編で。」）と「▶ 続きは本編で」の札。結末は出さない（ショートと同じ）。
