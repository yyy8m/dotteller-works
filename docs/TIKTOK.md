# TikTok の整え方と投稿の決まり

TikTok はオーナーが手で投稿する（API 連携なし）。投稿用の文面は各作品の `works/<作品>/tiktok.txt` にある。

## 1. プロフィール（最初に1回だけ設定）
TikTok アプリ → プロフィール → 「プロフィールを編集」で次のとおり入れる。

| 項目 | 入れる内容 |
|---|---|
| 写真 | `brand/icon.png`（チャンネルと同じアイコン） |
| 名前 | ドット語り｜名作と事件をドット絵で |
| ユーザー名 | dotgatari（設定済み） |
| 自己紹介 | 下の4行 |
| YouTube | 連携の欄はない。自己紹介に URL を書く |
| ウェブサイト | https://dotgatari.blogspot.com （入れる欄が表示されないときは後回しでよい） |

自己紹介（80字以内。URL は押せない文字だが、打ち込めば見られる）：
```
コードだけで描く、名作と事件
毎日18時更新
▶本編 youtube.com/@dotteller
▶ブログ dotgatari.blogspot.com
```
- YouTube のハンドルは 11/17ごろ @dotteller → @dotgatari に変える予定。変えたら自己紹介の `@dotteller` を `@dotgatari` に直す。
- ブログのアドレスを変えたら、`▶ブログ` の行も新しいアドレスに直す。
- 投稿文に書くのは本編の案内だけ（「本編は YouTube『ドット語り』で（プロフィールから）」）。動画ごとの URL は押せず、打ち込むのも大変なので書かない。

- ウェブサイトの欄は、アカウントの種類やフォロワー数によっては出ないことがある。出ないときは、YouTube の連携だけで十分（本編へはそこから行ける）。
- 再生リスト（プロフィールに並ぶ作品のまとまり）が使えるようになったら、「ドット語り 文庫」と「ドット語り 記録」の2つを作る。

## 2. 投稿の決まり
- 投稿するのは **TikTok 版（`works/<作品>/build/video/<n>_tiktok.mp4`）**。11/10 の三毛別から。
  - 尺は **60〜75秒**（TikTok のクリエイター報酬プログラムの対象が「1分以上の動画」のため）。本編全部ではなく予告編：完結させず、最後は「続きは、本編で。」の一言と「▶ 続きは本編で／YouTube『ドット語り』」の札で切る。
  - 冒頭2秒の決まりは YouTube ショートと同じ（結果・異常さから始める）。ループにはしない。
  - 作り方：`story.js` の `PLAN_TIKTOK`（ショートの冒頭 S1 → 本編の場面を3〜4つ → 締めの `T1`）、`python3 engine/tools/build.py works/<id> --tiktok`、`node engine/tools/export_video.js works/<id>/build/index_tiktok.html tall works/<id>/build/video/<n>_tiktok.mp4 30 1`。
  - 場面の `init` で、TikTok 版に入らないセリフを `at()` で参照するときは `ln(S, 'Lxx') ? … : 1e9` で守る（ないセリフは0秒扱いになり、絵が最初から先に進んでしまう）。
- 11/9 までの作品（ゲイシーまで）は YouTube ショート（`_short.mp4`、30〜45秒）をそのまま使う。
- 文面は `tiktok.txt` をそのまま貼る。
  - TikTok は本文のリンクを押せないので、URL は書かない。「本編は YouTube『ドット語り』で（プロフィールから）」と案内する。
  - 1行目はつかみにする。最後の行は問いかけにして、コメントを呼ぶ。
  - ハッシュタグは5個：作品名、作者名かジャンル、名作文学か事件解説、#ドット絵、#ドット語り。
- 投稿は YouTube の本編の公開（18:00）以降にする。本編より先に出すと、案内先がまだ見られない。
- 音は動画に入っているものを使う（TikTok の曲は足さない）。
- 記録シリーズのショートは血の描写を控えめにしてある。1行目に【閲覧注意】を入れる。
- 固定（ピン留め、最大3本）するもの：いちばん再生が多い動画1本、文庫の代表1本、記録の代表1本。

11/10 からは、毎日18:00以降に、その日 YouTube で公開した作品のショートを1本出す（YouTube のショートも18:00公開）。
制作のときに作る報告に、`tiktok.txt` の中身と TikTok 版のファイル（`_tiktok.mp4`）を入れ、ファイルはオーナーに送る（SendUserFile）。
