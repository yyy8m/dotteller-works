# TikTok の整え方と投稿の決まり

TikTok はオーナーが手で投稿する（API 連携なし）。投稿用の文面は各作品の `works/<作品>/tiktok.txt` にある。

## 1. プロフィール（最初に1回だけ設定）
TikTok アプリ → プロフィール → 「プロフィールを編集」で次のとおり入れる。

| 項目 | 入れる内容 |
|---|---|
| 写真 | `brand/icon.png`（チャンネルと同じアイコン） |
| 名前 | ドット語り｜名作と事件をドット絵で |
| ユーザー名 | dotgatari（設定済み） |
| 自己紹介 | 下の4行（62字。上限は80字） |
| YouTube | 「YouTube を追加」から @dotgatari のチャンネルを連携する |
| ウェブサイト | https://somosomo-cho.blogspot.com （入れる欄が表示されないときは後回しでよい） |

自己紹介：
```
ドットで描く、物語と記録。
📖文庫＝名作文学（土日）
🕯記録＝本当にあった事件（平日）
毎日19時更新／本編はYouTube
```

- ウェブサイトの欄は、アカウントの種類やフォロワー数によっては出ないことがある。出ないときは、YouTube の連携だけで十分（本編へはそこから行ける）。
- 再生リスト（プロフィールに並ぶ作品のまとまり）が使えるようになったら、「ドット語り 文庫」と「ドット語り 記録」の2つを作る。

## 2. 投稿の決まり
- 投稿するのは各作品のショート（縦長の動画）。ファイルは `works/<作品>/build/video/` にある、名前に `_tall.mp4` か `_short.mp4` が付いたもの。
- 文面は `tiktok.txt` をそのまま貼る。
  - TikTok は本文のリンクを押せないので、URL は書かない。「本編は YouTube『ドット語り』で（プロフィールから）」と案内する。
  - 1行目はつかみにする。最後の行は問いかけにして、コメントを呼ぶ。
  - ハッシュタグは5個：作品名、作者名かジャンル、名作文学か事件解説、#ドット絵、#ドット語り。
- 投稿は YouTube の公開と同じ日の19:00以降にする。本編より先に出すと、案内先がまだ見られない。
- 音は動画に入っているものを使う（TikTok の曲は足さない）。
- 記録シリーズのショートは血の描写を控えめにしてある。1行目に【閲覧注意】を入れる。
- 固定（ピン留め、最大3本）するもの：いちばん再生が多い動画1本、文庫の代表1本、記録の代表1本。

## 3. 今あるショートを出す順番（たまっている分）
一度にまとめて出さず、1日1〜2本に分ける。

| いつ | 作品 |
|---|---|
| 11/7（土）21:00ごろ | 文庫 #002 注文の多い料理店 |
| 11/8（日）12:00ごろ | 文庫 #001 蜘蛛の糸 |
| 11/8（日）19:00 | 文庫 #003 杜子春 |
| 11/9（月）12:00ごろ | 記録 #001 エド・ゲイン |
| 11/9（月）19:00 | 記録 #002 ジョン・ゲイシー |

11/10 からは、毎日19:00に、その日 YouTube で公開した作品のショートを1本出す。
制作のときに作る報告に、その日の `tiktok.txt` の中身とショートのファイル名を入れる。
