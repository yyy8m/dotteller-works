# 投稿スケジュール

| シリーズ | 頻度 | 曜日・時刻（日本時間） |
|---|---|---|
| ドット語り 記録（Wikipediaシリーズ・海外の事件） | 週3本 | 月・水・金 19:00 |
| ドット語り 文庫（青空文庫シリーズ） | 週1本 | 土 19:00 |

- YouTube本編・ショート・ブログを同じ時刻に予約公開する（`publish.json` の `publish_at`）。
- 制作は定期作業で行う：毎週 水曜 13:43（その週の金・土の分）と 土曜 13:43（翌週の月・水の分）。手順は `docs/PRODUCTION.md`。
- TikTok はオーナーが手動投稿（`works/<作品>/tiktok.txt` を使う）。
- 予約は公開の2日前までに入れる。予約中の動画は YouTube Studio の「限定公開/非公開」で事前に確認できる。

## 記録シリーズの作り方の決まり
- 本編は5〜7分（12章前後、台本30行前後）。ショートは本編から作る60秒前後の予告編（`build.py --short` / `PLAN_SHORT`）。
- 事実は Wikipedia の記事で確かめられる範囲だけを使い、記事を「参考」として動画・ブログに載せる。確証のない話は「〜と言われています」とする。
- 殺害の場面・遺体・血はドット絵で描いてよい（銃撃・刺す瞬間・血だまり・倒れた体・壁に映る影など）。
  実在の被害者の遺体の損壊を細かく描くことはせず、影・シルエット・懐中電灯の光の中で見せる。
- 犯人を美化しない。最後に被害者を悼む一言を入れる。被害者の名前は必要なときだけ。
- 1作品に1場面、犯人の顔のドアップのホラー調の場面（`horrorCloseup`、ナレーションなし約4秒）を入れる。
- 画面内の文字（看板・車・カード・巻物）は枠からはみ出さないこと。書き出した画像で一つずつ確かめる。
- 三毛別羆事件のように犯人が動物の回も同じ決まりで作る（ドアップは羆の顔）。
- サムネとショートは血の描写を控えめにする（YouTube の年齢制限・おすすめへの影響を避けるため）。本編の説明欄には「閲覧注意」と表現の注意書きを入れる。
- 説明欄は「つかみ → この動画でわかること → チャプター（{CHAPTERS}）→ コメントの呼びかけ → リンク → 注意書き・参考 → シリーズ紹介 → クレジット」の順。
