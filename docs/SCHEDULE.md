- しばらくは「奇妙な話・心理ホラー・狂気を感じるミステリー」を中心にする（チャンネルの見る人がホラー・ミステリー好きのため）。ただし絞りきらず、2本に1本ほどは怪奇寄りの名作文学（変身・罪・死を扱うもの）も入れる。

## 題材のバランス（記録）
- ミステリー（未解決・謎の事件）を週1本ほど混ぜる（事件ものが中心）。
- 日本の事件は週10本のうち4本前後まで（2本化に合わせて調整）。同じ国の事件を2日続けて置かない。アメリカに偏らないよう、ヨーロッパ・ロシア・南米なども混ぜる。
- 被害者や遺族がいまも多く存命の、ごく最近の事件（おおむね2000年代以降）は避ける。

## 記録シリーズの作り方の決まり
- 本編は5〜7分（12章前後、台本30行前後）。文庫も同じく本編5〜8分（原作の流れを省きすぎない。短い予告はショートの役目）。ショートは本編から作る30〜50秒の予告編（`build.py --short` / `PLAN_SHORT`）。
- 事実は Wikipedia の記事で確かめられる範囲だけを使い、記事を「参考」として動画・ブログに載せる。確証のない話は「〜と言われています」とする。
- 殺害の場面・遺体・血はドット絵で描いてよい（銃撃・刺す瞬間・血だまり・倒れた体・壁に映る影など）。
  実在の被害者の遺体の損壊を細かく描くことはせず、影・シルエット・懐中電灯の光の中で見せる。
- 犯人を美化しない。最後に被害者を悼む一言を入れる。被害者の名前は必要なときだけ。
- 1作品に1場面、犯人の顔のドアップのホラー調の場面（`horrorCloseup`、ナレーションなし約4秒）を入れる。
- 画面内の文字（看板・車・カード・巻物）は枠からはみ出さないこと。書き出した画像で一つずつ確かめる。
- 三毛別羆事件のように犯人が動物の回も同じ決まりで作る（ドアップは羆の顔）。
- サムネとショートは血の描写を控えめにする（YouTube の年齢制限・おすすめへの影響を避けるため）。本編の説明欄には「閲覧注意」と表現の注意書きを入れる。
- 説明欄は「つかみ → この動画でわかること → チャプター（{CHAPTERS}）→ コメントの呼びかけ → リンク → 注意書き・参考 → シリーズ紹介 → クレジット」の順。
- ハッシュタグ（説明欄の最後の行）: YouTube はタイトルの上に最初の3つだけを出すので、順番は「作品名・ジャンル・#ドット語り」。
  - 本編は合わせて9〜11個。続けて検索されやすい語（記録: #事件解説 #実話 #海外の事件／#日本の事件 #殺人鬼 など、文庫: #朗読 #名作文学 #青空文庫 #あらすじ など）、#ドット絵、英語名を並べる。
  - ショートは6〜7個で、最後に #Shorts。
- タグ（`tags`）: 作品名の表記ゆれ（中黒あり・なし・英語）、「〜 あらすじ」「〜 モデル」など検索される言い回し、ジャンル、ドット絵、ドット語り、DOTGATARI。合計400字以内。
- TikTok は `docs/TIKTOK.md` の決まりに従う（URL は書かない、ハッシュタグ5個、YouTube の公開後に投稿）。ブログのラベルには作品名とジャンル（シリアルキラー、未解決事件、芥川龍之介 など）を足す。
- 人物の声に女性の声（mei）を使ったら、説明欄とブログのクレジットに "mei"（名古屋工業大学・CC BY 3.0）を入れる。
